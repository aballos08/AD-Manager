⭐ Features

👤

User Management

Complete user lifecycle management from a single interface.

  • Search by username, name, email, department
  • Check locked account status
  • Reset passwords with complexity validation
  • Unlock locked accounts
  • Create new users with all attributes
  • Clone users with group memberships
  • Enable / Disable accounts
  • Move users between OUs
🏷

Group Management

Manage security and distribution groups effortlessly.

  • Create Global, DomainLocal, or Universal groups
  • Security or Distribution group types
  • Add / Remove members
  • View group membership lists
  • Search across all groups
🖥

Computer / Workstation

Manage every machine on the domain from one place.

  • List all computers and workstations
  • Enable / Disable computer accounts
  • Reset computer account (rejoin domain)
  • Move computers between OUs
  • View OS, location, and managed-by info
📋

Group Policy (GPO)

View and link Group Policy Objects without GPMC.

  • List all GPOs with version info
  • Link GPOs to any OU
  • View GPO file paths and metadata
  • Search GPOs by display name
📁

Organizational Units

Manage the OU structure of your domain.

  • List all OUs in the domain
  • Create new OUs
  • View OU details and DN
  • Copy DN to clipboard
📊

Dashboard & Reports

At-a-glance overview with one-click CSV export.

  • Real-time statistics cards
  • Locked accounts report
  • Disabled accounts / computers reports
  • Never-logged-on users
  • Password expired users
  • Export any report to CSV

🚀 Quick Start

Installation & Launch

1
Install Python dependencies
pip install -r requirements.txt
2
Launch the application
python main.py
3
Enter your AD domain credentials in the connection dialog and click Connect

📁 Project Structure

main.py # Application entry point requirements.txt # Python dependencies index.html # This documentation page core/ ad_connection.py # LDAP connection, user/group/computer/GPO operations ui/ main_window.py # Main window with sidebar navigation login_dialog.py # AD connection dialog with SSL support user_management.py # User search, CRUD, password reset, clone group_management.py # Group CRUD and membership management computer_management.py # Computer/workstation management policy_management.py # GPO listing and linking ou_management.py # OU listing and creation reports_panel.py # Dashboard, reports, CSV export styles.py # Application theming and colors widgets.py # Reusable custom widgets utils/ helpers.py # Password validation, formatting, generation

🔐 Required AD Permissions

The domain account used to connect must have the following permissions:

  • Read — Access to AD objects (users, groups, computers, GPOs, OUs)
  • Reset Password — For password change operations
  • Modify — For updating user/computer attributes
  • Create/Delete — For creating new objects (users, groups, OUs)
  • Group Management — For adding/removing group members
